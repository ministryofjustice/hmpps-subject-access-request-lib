# 2.1.0

## SarReportTest change to include stylesheet in html report

When SarReportTest has been implemented the expected report output HTML will now be expected to have matching standard
stylesheet CSS. Any tests which have implemented this test interface will need the expected HTML output to be updated to
account for this. Assuming no other changes have been made to the template the new expected HTML output can be generated
by running the implementing test with the env var `SAR_GENERATE_ACTUAL` set to `true`.
